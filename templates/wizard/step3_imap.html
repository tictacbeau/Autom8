IMAP Fallback

Backup email access if the Graph API is unavailable.

What is IMAP? IMAP is a standard email protocol that lets applications read your mailbox directly. It is used here as a backup: if the Graph API fails for any reason, the tool will silently switch to IMAP and continue without interruption. The IMAP server for Microsoft 365 is outlook.office365.com:993 (SSL).
Using an App Password (recommended)

If your organisation has disabled basic authentication, you may need a Microsoft 365 App Password:

  1. Sign in at mysignins.microsoft.com/security-info
  2. Click + Add sign-in method → App password
  3. Give it a name (e.g. "Remittance Tool") and copy the generated password
  4. Paste it in the password field below — it replaces your regular password

App passwords are available only if your admin hasn't blocked them entirely. If neither regular passwords nor app passwords work, IMAP may be disabled at the tenant level — in that case, use the Graph API (Step 2) or Folder Watch (Step 4).
