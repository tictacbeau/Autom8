Microsoft Graph API

Primary email access via OAuth2 — free, secure, and automatic.

  1. Go to portal.azure.com and sign in with your Microsoft 365 work account.
  2. In the search bar at the top, type App registrations and click it.
  3. Click + New registration.
  4. Enter any name (e.g. Remittance Tool).
  5. Under Supported account types, select "Accounts in this organizational directory only".
  6. Under Redirect URI, select Public client/native and enter: http://localhost
  7. Click Register.

After registration, you'll see the Overview page. Copy two values:

  • Application (client) ID — looks like xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
  • Directory (tenant) ID — same UUID format

Paste them into the fields below.

  1. In your App Registration, click API permissions in the left menu.
  2. Click + Add a permission.
  3. Choose Microsoft Graph → Delegated permissions.
  4. Search for Mail.Read, check it, and click Add permissions.
  5. Click Grant admin consent (if you are an admin) — or ask your IT admin to do this.

If you can't grant admin consent, you can still authenticate — you'll just be prompted to consent yourself during sign-in.

Connection failed
Troubleshooting: Verify the Client ID and Tenant ID are correct. Ensure Mail.Read permission is granted. Check that the redirect URI http://localhost is registered as a Public client URI in Azure.
