Local Folder Watch

Always available — no credentials, no network required.

The folder watch is always active. No credentials or configuration are required for this tier.
How it works

The tool continuously monitors a designated watch folder. Any file you drop into it is automatically processed against your pending deposit queue using the same matching logic as the email tiers.

Watch folder location
{{ watch_dir }}

This folder is inside the project directory. Nothing is ever written outside the project folder.

How to save emails from Outlook
  1. Open the remittance email in Outlook.
  2. Go to File → Save As.
  3. Choose Outlook Message Format (*.msg) or EML and navigate to the watch folder.
  4. The file is picked up automatically within a few seconds.

You can also drag PDF or image remittances directly into the watch folder — they'll be processed the same way.

When to use Folder Watch
  • IMAP and Graph API are both unavailable due to IT policy
  • A specific payor sends remittances in a format that needs manual review before processing
  • You want to manually curate which emails are processed for a particular payor
